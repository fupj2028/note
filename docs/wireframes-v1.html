看线稿时请重点确认这几件事：
1. 列表项要显示什么：标题 + 正文前两行 + 时间 + 标签，置顶的单独分组放最上面 —— 够不够？还想加什么？
2. 编辑页 = 阅读页：点一条笔记直接进编辑态，改完自动保存，没有单独的"阅读模式"。这样最省事，你接受吗？
3. 复制粘贴入口放哪：正文里长按走系统选择（③ 里的浮动条），整条复制放在长按面板（④ 的「复制全文」）。
4. 分类怎么用：顶部一排 chip 做筛选，加 / 删 / 隐藏都在 ⑨ 分类管理页里改，① 那排最后一格「管理」是入口。第一版不做多级文件夹，够吗？
5. 回收站：保留 30 天，可恢复、可彻底删（⑤）。
6. 导出：范围选"全部 / 当前这条"，格式选 Markdown 或纯文本（⑦）。
7. 分类管理页已补上（⑨）。"首次启动引导"没做，需要吗？
